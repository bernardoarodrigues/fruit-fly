# Or42a summary experiment provenance

The rate source and its limits are documented in
`docs/or42a-primary-assay.md` and `validation/or42a-primary/ATTRIBUTION.md`.
Primary citation: de Bruyne M, Clyne PJ, Carlson JR (1999), J Neurosci
19:4520–4532, https://doi.org/10.1523/JNEUROSCI.19-11-04520.1999 .
No original paper/figure is redistributed with this experiment. The totals
149 and 57.67908699377742 Hz are declared combinations of published baseline
and separate response summaries, not measured matched-cohort total rates.

MaleCNS v1.0 identifiers, connectivity and annotations derive from Berg et al.,
Cell (2026), https://doi.org/10.1016/j.cell.2026.08.015 , CC BY 4.0,
https://creativecommons.org/licenses/by/4.0/ . The full graph and exact source
IDs are hash-pinned in the plan. Changes are source selection for imposed input
and an explicit outgoing-delivery intervention; no graph weight is fitted or
changed. Simulation outputs are model-generated, not source-authored data.

The 1999 pb1A-to-Or42a/VM7d correspondence uses the separate anatomical audit
and DoOR crosswalk; see `validation/door/ATTRIBUTION.md` for CC BY-SA 4.0 DoOR
and CC BY 4.0 anatomical-source attribution. DoOR's unmerged stored response
numbers are not used as rates in these trials. There is no source-author
endorsement implied. No license for unrelated repository code is asserted.
