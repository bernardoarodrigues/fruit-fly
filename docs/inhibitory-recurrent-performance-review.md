# Recurrent performance runner: source review and retained compilation failure

This is a bounded review of the performance runner's source, amendment and archive schema. It is not an independent review of the ensuing full-graph results. The reviewer authored the separate experimental kernel; that kernel's independent source review is [recorded separately](inhibitory-recurrent-kernel-independent-review.md). No full graph, body or neural performance trial was executed by this review.

The original [runner](../scripts/probe_inhibitory_recurrent.py), SHA256 `3a87246dbdf51c7bb8a600f1ea564624fbc409cb4ed7f32b00737b14944e94cc`, was inspected for API use, control parity, output retention and resource handling. Syntax compilation, a CLI-equivalent import and an archive-only roundtrip with dummy NaN/Inf arrays passed. These checks did **not** compile the Numba scalar timing function. Consequently this review missed its dynamic indexing of the heterogeneous seven-field `hybrid_step` return tuple. This was an actual startup defect, not a neural or numerical failure.

The [initial frozen plan](../validation/inhibitory-recurrent-performance-plan.json), SHA256 `83174a7776c5794ece78fbebf1127cbf468f910371c0e8d4e83428b3de9cd550`, and [failed receipt](../validation/inhibitory-recurrent-performance/results.json), SHA256 `005c80ea80f5b38ffe9d7336ba7b24a0bd7b37c8489f6edc629b581030fdb134`, remain unchanged. The receipt records the Numba `TypingError`, successful two-cell warmups, retained input stream, all source rechecks passing, and an empty `arms` list. The failing call precedes graph loading. There is no full-graph outcome from this attempt.

The reviewed [v2 runner](../scripts/probe_inhibitory_recurrent_v2.py), SHA256 `ac9d61bfb32733ea50dce70a54e2902d7855e58c90c14503eb0d78cb8ece0b24`, replaces the loop's dynamic tuple indexing with seven literal field assignments. This preserves field order, float-array storage and the voltage checksum. The remaining diff adds separate v2 plan/output paths and pins the original source, plan and failed receipt. It changes no solver, graph, timestep, arm, input, tolerance or budget. No additional source blocker was identified in this amendment. Its actual compilation and execution evidence belongs to the producer's v2 artifacts, rather than the earlier import-only check.

The source contract runs an original-engine reference followed by C0, C1, H0 and H1, each for 50 ms with seed 11 and the same 36-source 11 Hz input stream. C0 must match the fresh reference's full-state digest every 5 ms and final arrays byte for byte before altered arms execute. Ordered spikes, candidate and applied masks, edge counts, RNG boundaries and saved earlier-prefix summaries add separate comparisons. The earlier prefix alone has no full checkpoint. Reference applied events are inferred from candidates and same-tick source spikes; experimental applied writes are instrumented. Common candidates do not imply common applied events after recurrence changes.

Failure handling preserves available checkpoints and marks an uncaught in-progress transition incoherent. Nonfinite extrema become JSON null with explicit flags, while NPZ arrays retain their actual nonfinite values. Both ordinary exceptions and keyboard interruption enter the same retention path. Each pinned source is checked again at finalization. These are source-level guarantees with ordinary filesystem/process limits; a hard kill cannot guarantee a final receipt.

The 600-second, 2-GiB output and 8-GiB peak-RSS limits are sampled checks, including after final checkpoint archives. A chunk or archive can overshoot. Initial source hashing and final source/artifact hashing and report writing are explicitly outside enforcement. Compilation, stream creation and the separate warmed scalar workload count toward execution time. Process-lifetime peak RSS is conservative. Quiet 50 ms timing and a repeated independent scalar grid cannot establish later stimulus workload cost, physiological amplitude/timing, stimulus contrasts, seed robustness or persistent-activity control. This review does not select or promote H1.
