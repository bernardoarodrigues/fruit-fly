# Observational navigation metrics

[fruitfly/navigation_metrics.py](../fruitfly/navigation_metrics.py) adds three pure observational functions. It imports only NumPy and the standard library. No encoder, decoder, controller, neural parameter, runtime default, or anatomical selection changes are made.

`spike_activity(spike_ticks, spike_indices, cohorts, bin_edges_ticks, *, dt_s, observed_interval_ticks, windows=None)` accepts actual recorded emitted spikes. Ticks are nonnegative integers, ordered in time; paired graph indices have the same length. Bins and named windows such as `odor_ON`/`odor_OFF` use half-open tick intervals. `dt_s` must be positive, and the observed interval must declare continuous recording coverage. Requested event rates are not accepted as a substitute for emitted spikes.

Cohorts map names to ordered unique indices. `None` means missing annotation; `[]` means an explicitly empty selection. Overlap is permitted, so a full DN cohort and distinct DNa01/DNa02 cohorts can coexist without implicit merging. Supply the independently audited `DN_all` manifest selection; this module does not infer DN membership from a name prefix.

The returned `bins` and `windows` objects contain requested durations, observed durations, and `complete`/`partial`/`unobserved` status. Each cohort preserves per-neuron `observed_counts` and `per_neuron_rate_hz`. Partial counts describe only the observed intersection; their rates stay NaN. Fully observed silent cells have exactly zero counts/rates. Missing cohorts have None arrays; empty-cohort mean rates are NaN. Archive validity/status alongside numerical arrays rather than replacing NaN with zero. Named window order is in `window_names`.

`planar_kinematics(times_s, positions_mm, yaw_rad, *, local_airflow_world_mm_s=None, speed_floor_mm_s=.1, wind_floor_mm_s=1e-12)` accepts N finite poses and strictly increasing seconds. Positions have shape `(N,2)` or `(N,3)`; only world XY is analyzed. Positive yaw is counterclockwise. Adjacent chords yield N−1 forward/lateral/speed/yaw-rate samples at interval midpoints. Heading curvature is yaw-rate divided by planar speed. Distinct N−2 path-turn and path-curvature samples compare adjacent chord directions: turn divided by elapsed velocity-midpoint time or mean neighboring chord length. These are sampled polygonal-path estimates, not an assumption that heading follows travel direction.

Curvature is undefined below the configurable speed floor. Exact half-turn yaw changes or path reversals have no inferred signed turn; their relevant metrics remain NaN. Pose sampling must resolve less than a half-turn between samples: hidden full rotations cannot be recovered. The 0.1 mm/s floor is a declared analysis threshold, not calibrated biological stopping behavior.

Wind has shape `(N−1,2|3)` and means sampled **physical air velocity in world coordinates**, not apparent airflow after subtracting body/antenna velocity. Upwind opposes this horizontal vector. A caller holding sensor-relative airflow must first restore sensor velocity and retain the sampling-point provenance. Zero or below-floor wind and missing wind remain undefined, so moving through still air does not create a fictitious upwind target. Projection onto upwind is in mm/s; heading cosine is dimensionless. Exactly opposed headings retain cosine −1 but have an undefined signed heading error. Reflection through world X negates yaw, lateral velocity, heading/path curvature and signed wind-heading error while preserving speed, forward velocity, upwind velocity projection and heading cosine.

`circular_activity(weights, indices, *, angles_rad=None, coordinate_label=None)` requires an explicit graph-index-to-angle map and provenance label. Missing cell coordinates stop the calculation; no unannotated cells are silently dropped. It returns a descriptive first circular moment, not an FB bump detector. Silent activity has undefined phase/resultant; a cancelling first moment has undefined phase. Uneven/repeated coordinate sampling may itself bias the moment. Connectome instance column tokens do not supply angles automatically, and neither a cohort mean nor a nonzero moment establishes localized biological persistence.

Focused analytic tests are in [tests/test_navigation_metrics.py](../tests/test_navigation_metrics.py): **25 passed**. They cover exact ON/OFF boundaries, arbitrary cohort order/overlap, missing versus silent data, partial exposure, irregular timing, yaw wrap, separate path/heading turns, reflection signs, zero-wind and speed-floor boundaries, angular ambiguity, explicit circular mapping, and caller-array nonmutation. No simulator or model run is part of this validation.
