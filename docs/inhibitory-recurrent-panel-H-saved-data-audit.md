# Independent H-arm saved-data audit

All six actual H0/H1 no-input trials, covering seeds 11, 12 and 13, have each passed **53,827/53,827 independent saved-data checks**. Each was audited once, after its authoritative terminal completed; none produced a failed review. Their [summary receipt](../validation/inhibitory-recurrent-panel-H-noinput-audit-summary.json) links and hashes all six original reviews. The reader's earlier bounded preflight passed **30/30 checks**. The reader only accepts a terminal-complete H0 or H1 trial and refuses to overwrite a previous review or reference archive. It imports no neural kernel, simulator, producer, archive writer, or metric helper.

The actual seed-11, three-second controls are [H0 ordinal 16](../validation/inhibitory-recurrent-panel-16-H0-seed11-no_input-H-review.json) and [H1 ordinal 17](../validation/inhibitory-recurrent-panel-17-H1-seed11-no_input-H-review.json). Both reviews decoded all 600 chunks, 611 archives and 19,319 arrays. They reconstructed zero spikes, zero direct candidates/applied events and zero selected incoming edges; source, nonsource and forward-motor window counts were all zero. All reviewer dependencies matched their start/end hashes. The reviews took 3.11 and 3.06 seconds, respectively, without executing a network.

Each control retained 1,800 reference rows, representing one unique input tuple `(-52 mV, 0 mV, 0, 0.1 ms)`. The independent adaptive, 64-node and ODE results all matched the production value exactly at stored precision, with quadrature error estimate `1.274e-15 mV` and no threshold-margin ambiguity. Their [H0 reference array](../validation/inhibitory-recurrent-panel-16-H0-seed11-no_input-H-review-references.npz) and [H1 reference array](../validation/inhibitory-recurrent-panel-17-H1-seed11-no_input-H-review-references.npz) have identical SHA-256 `4d895c9ab84bfc737a7545517c194823f25f024d3a5ba0d777c8fb82fed91896`. These silent controls exercise rest-state behavior; they provide no recurrent stimulated-response or nonzero-conductance evidence and do not distinguish the two refractory packages.

The frozen reader is [`review_inhibitory_recurrent_panel_H.py`](../scripts/review_inhibitory_recurrent_panel_H.py), SHA-256 `80a68d09ed3d028a7bc193ab5471c270bf6576018c7cd04dab6852a500d64237`. It uses the already reviewed independent archive decoder and the separately validated [numerical reference](inhibitory-panel-reference-audit.md). At both start and finish it hashes its own source, decoder, numerical helper, and helper-validation receipt. The helper must match `2a20ac9ed6b5dfd312b7f7aeb83028920c403f8972374213d731fcafddbea743`, with the completed, passing 125-case validation receipt `4985dac16fe3192c6e703cafa3aaf42ab4251c75a5952baef8b65aeb950abafd`.

For each completed trial, it independently decodes all 600 chunk archives and boundary checkpoints. It reconstructs ordered spike counts, source candidate/applied masks from saved uniforms, logical RNG boundaries, all-cell refractory history and pending queues, and the selected-cell incoming edge order and dispositions. It checks all 48 selected p/h traces by applying decay, delayed weights and the appropriate refractory/reset package to saved events. It also checks selected voltage hold, strict threshold, direct input and reset arithmetic. Complete checkpoint arrays are authenticated, and their membership, clocks, counts, queue, last-spike history and selected states are checked. The unsaved all-cell interval trajectories are not reconstructed.

For H integration, it joins every retained global reference and each target's first available interval to the exact stored before-state. Duplicate reasons remain attached to the same tick/cell. A global candidate must dominate the retained selected population under its stated score. Each distinct saved `(v,p,h,dt)` is then evaluated with independent Brent inversion/adaptive quadrature, a separately generated 64-node rule, and a time-domain three-state ODE. The frozen gates remain production–quad and production–64 ≤ `1e-8 mV`, ODE–quad ≤ `2e-8 mV`, and the quadrature estimate ≤ `1e-9 mV`. Repeated identical tuples reuse the calculated reference. The receipt and a separate numeric NPZ retain the inputs and outputs, including threshold-margin ambiguity.

An ordinary helper failure records its exact row, inputs, failed method and any completed helper values. A `KeyboardInterrupt` records the exact current input tuple and retains already completed audit rows and cached evaluations; the helper's interrupted internal method and unfinished local values remain unknown. Either case produces a failed review, with the number of fully audited chunks stated. Incomplete, interrupted, correctness-failed or retention-failed producer trials are excluded from this complete-trial reader; they require a separately scoped prefix review.

The [preflight plan](../validation/inhibitory-recurrent-panel-H-review-preflight-plan.json) was saved before evaluation. Its [receipt](../validation/inhibitory-recurrent-panel-H-review-preflight-results.json) retains the 30 checks, injected failure contexts and hashes of the [reconstructed arrays](../validation/inhibitory-recurrent-panel-H-review-preflight-arrays.npz). It checked exact H0/H1 p/h reconstruction on the existing 128-cell, 300-tick saved fixture, with both signs of accepted edges and firing/refractory intervals. A retained, explicitly mocked dispatch fixture tested later target availability, duplicate global labels and the valid `p=0, h>0` ratio of negative infinity. Only its one previously saved scalar input was numerically evaluated. Altered predecessor and missing-population controls were detected; injected interruption and solver failure preserved earlier rows/cache. This was neither a new network run nor a physical trajectory test of the mocked dispatch fixture.

Once an H trial has a completed terminal, reproduce its audit with, for example:

```sh
.venv/bin/python scripts/review_inhibitory_recurrent_panel_H.py --ordinal 16
```

The reader writes new `validation/inhibitory-recurrent-panel-<trial>-H-review.json` and `-H-review-references.npz` files. Preserve the first result even if it fails. The completed [C0 reviews](inhibitory-recurrent-panel-saved-data-audit.md) and their frozen readers remain separate and unchanged.

The audit cannot prove global extrema ranking over cells whose interval states were not saved, or independently classify every full-graph accepted/unavailable edge. It reconstructs all delivery visits and exact selected-target dispositions, and checks the producer's global partition. Independent H integration is limited to the predetermined saved reference intervals. Numerical agreement and a voltage lower bound do not establish physiological amplitude/timing, sensory discrimination, seed robustness, natural behavior, or eligibility to promote H1.
